# ONSvisual legacy visualisations

This repository preserves the static visualisation sites removed from
`ONSvisual/ONSvisual.github.io` by commit
`e3a1ee854e2c2a4cd3cc6c0d93446b83e4409934` (`remove legacy vis`).

The site files were restored unchanged from that commit's parent,
`7eb4351bff59aa08394e304cd9a74dd0dcb476da`, and are published with
GitHub Pages. The legacy `onsvisual.github.io/<path>/` URLs are redirected
to their matching paths in this repository's Pages site.

Do not modernize or move a visualisation without first preserving its legacy
redirect and checking its embedded asset URLs.
